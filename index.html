STEAMLab · Matemáticas multisensoriales · Primaria

Números que se tocan, se escuchan, se mueven y se viven

Este recurso interactivo para GitHub presenta un aula multisensorial de matemáticas para niñas y niños de primaria. Incluye luces, sonidos, movimiento y propuestas guiadas para vista, oído, tacto y, pedagógicamente, también olfato y gusto mediante rincones simbólicos.

Entrar al aula interactiva Ver instrucciones

Vista

Números y figuras geométricas se encienden, cambian de color y responden con destellos.

Oído

Al interactuar con los objetos, el sistema reproduce tonos suaves y patrones sonoros.

Tacto

Los elementos se mueven, saltan o vibran visualmente al hacer clic o tocar la pantalla.

Olfato y gusto

Se incorporan rincones simbólicos con tarjetas de aromas y sabores para actividades reales guiadas.
