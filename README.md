# STEAMLab · Matemática multisensorial para primaria

## Nombre sugerido del repositorio
`steamlab-matematica-multisensorial`

## Contenido
- `index.html` → página de presentación.
- `aula-interactiva.html` → aula multisensorial interactiva.
- `README.md` → instrucciones de publicación y uso.

## Propósito pedagógico
Este recurso propone un ecosistema de aprendizaje multisensorial de matemáticas para primaria (aprox. 6 a 10 años). Integra:
- **Vista:** números y figuras con luces, color y contraste.
- **Oído:** sonidos suaves generados al interactuar.
- **Tacto:** respuesta visual al toque o clic (saltos, giros y movimiento).
- **Olfato y gusto:** rincones simbólicos dentro del recurso digital que inspiran actividades reales, seguras y guiadas por el docente.

## Cómo publicarlo en GitHub Pages
1. Crea un repositorio nuevo con el nombre: `steamlab-matematica-multisensorial`.
2. Sube los tres archivos al repositorio.
3. Ve a **Settings > Pages**.
4. En **Build and deployment**, selecciona:
   - **Source:** Deploy from a branch
   - **Branch:** `main` / `/root`
5. Guarda los cambios.
6. Espera unos minutos. GitHub publicará la página.

`https://luisctito-sketch.github.io/steamlab-matematica-multisensorial/`

## Cómo usar el aula interactiva
- Pulsa **Entrar al aula interactiva** desde `index.html`.
- Toca o haz clic en números, figuras, fichas o rincones sensoriales.
- Usa la barra superior para:
  - cambiar velocidad,
  - activar o desactivar sonido,
  - activar o desactivar luces,
  - mostrar u ocultar etiquetas,
  - lanzar nuevos retos,
  - usar pantalla completa.

## Recomendaciones didácticas
- Invitar a los niños a **explicar lo que observan**.
- Relacionar el recurso con materiales físicos del aula: bloques, fichas, cuerdas, saquitos aromáticos seguros y alimentos apropiados si se trabaja gusto.
- Ajustar la estimulación según sensibilidad: sonido bajo, menos luces o etiquetas ocultas.

## Importante
El recurso digital **no emite olor ni sabor reales**. Esos sentidos aparecen aquí como orientación pedagógica para que el docente amplíe la experiencia en el aula física de manera segura.
